# Current API Inventory

This inventory reflects the current FastAPI backend in `/root/synapse` as inspected for the architecture migration. It is documentation-only and does not change routes, production behavior, auth, roles, licenses, or legacy static apps.

## Reading notes

- All active application routes are mounted under `/api/v1`.
- `content_readonly.py` is mounted with prefix `/content`.
- `sync_progress.py` is mounted with prefix `/progress`.
- `ai_mentor.py` is mounted with prefix `/ai-mentor`.
- `content_seed.py` defines `/content/seed`, but it is not currently included in `backend/app/api/v1/routes.py`.
- Many admin/content endpoints return raw `dict`; those require explicit TypeScript contracts before migration.
- Auth means current code requires a bearer token or content-manager authorization check. Some user-specific query endpoints still expose `userId` query access and need review before shared client hardening.
