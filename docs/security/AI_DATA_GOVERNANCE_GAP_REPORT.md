# AI Data Governance Gap Report

Provider configuration and online/offline fallback exist, but no approved end-to-end policy proves prompt/response retention, PII redaction, minors' data handling, teacher/parent visibility, provider contract boundaries, model/version provenance, cost/rate controls, prompt-injection resistance or scientific safety escalation.

Target gateway: classify/redact before provider calls; prohibit unnecessary identifiers; tenant-scoped consent and visibility; default minimal/no retention; approved provider/model allowlist; encrypted secret store; per-user/tenant budgets; prompt and retrieved-source provenance; uncertainty labeling; scientific safety rules; content filters; human handoff; provider kill switch; immutable policy/audit metadata without storing sensitive prompt bodies by default. DPIA, retention and provider selection require owner/legal/architect approval.
