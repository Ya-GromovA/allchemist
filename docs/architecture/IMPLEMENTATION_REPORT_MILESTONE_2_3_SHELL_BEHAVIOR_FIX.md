# Implementation Report — Milestone 2.3 Shell Behavior Fix

## Summary

Milestone 2.3 fixes the student dashboard shell behavior without switching production routes. The dashboard preview now behaves as a reusable app shell: the desktop sidebar stays pinned while the main content scrolls independently, navigation sections can expand/collapse, nested active states are modeled in typed sidebar config, and responsive layouts avoid horizontal overflow.

## Fixed Behavior

- Converted the student dashboard preview into a fixed-height desktop app shell.
- Kept sidebar logo, navigation, license card, and collapse/preview control inside the sidebar column.
- Made the nav region internally scrollable while sidebar footer content remains anchored.
- Restored readable UTF-8 Russian strings in the approved dashboard component.
- Added typed nested sidebar items and match paths for future route-aware highlighting.
- Updated the visual smoke script to validate shell behavior, submenu interaction, mojibake, and horizontal overflow.

## Sidebar Behavior

- Desktop shell uses `height: 100dvh` and `overflow: hidden`.
- Main content uses independent vertical scrolling.
- Sidebar uses full viewport height and does not move when main content scrolls.
- Sidebar navigation can scroll internally when menu content exceeds available height.
- Tablet/mobile switch back to document flow so the layout remains accessible on small viewports.

## Accordion Behavior

`Визуализация` now expands/collapses with:

- `3D-молекулы`
- `Симуляторы`
- `Микроскоп`
- `3D-клетка`
- `Анатомия`

`Справочники` now expands/collapses with:

- `Таблица элементов`
- `Формулы`
- `Законы и константы`
- `Реакции`

Accordion controls use real buttons, `aria-expanded`, `aria-controls`, keyboard-accessible native behavior, chevron rotation, smooth CSS transitions, and reduced-motion support.

## Active Route Behavior

- `/design-preview/student-dashboard` and `/dashboard/student` map to `Главная`.
- Sidebar model now supports `matchPaths` on top-level items and child items.
- Future nested routes can activate their parent section and child item through config:
  - `/modules/visualization/molecules`
  - `/modules/physics`
  - `/modules/biology`
  - `/reference/periodic-table`
