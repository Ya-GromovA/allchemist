Редакционный маршрут без автопубликации

  1. ИсточникСохранить автора, организацию, ссылку и данные о лицензии.
  2. ЧерновикДобавить авторский блок без копирования учебника.
  3. ПроверкиАвтор, научред, методист, контентная и юридическая проверка.
  4. Проверка перед публикациейПубликация разрешается только после источников, лицензии и проверки.

Очереди проверки и дедупликация

Материалы распределяются по статусам проверки. Дубли по content hash блокируются, а публикация требует юридической проверки и существующих источников в реестре.
